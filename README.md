# 사진 영어 문제 생성기

사진 속 영어 단어와 문장을 분석해 학습자 수준을 추정하고, 맞춤형 영어 문제를 생성하는 Next.js 웹앱입니다.

## 주요 기능

- 카메라 또는 이미지 파일 업로드
- 사진 속 영어 텍스트 추출 및 정리
- CEFR 기반 학습자 수준 추정
- 단어 샘플 5개 추출
- 문맥 빈칸, 유의어, 반의어, 단수와 복수 문제 생성
- 화면에서 바로 객관식 풀이 및 채점
- `OPENAI_API_KEY`가 없을 때 예시 학습지 표시

## 실행

```bash
npm install
copy .env.example .env.local
npm run dev
```

브라우저에서 `http://localhost:3000`에 접속합니다.

## 환경 변수

```bash
OPENAI_API_KEY=your_openai_api_key
OPENAI_MODEL=gpt-5.4
```

## 주요 파일

- `app/page.tsx`: 사진 업로드, 분석 결과, 문제 풀이 UI
- `app/api/worksheet/route.ts`: OpenAI Vision 기반 학습지 생성 API
- `app/globals.css`: 전역 스타일

# 중3 수학 개념 설명 트레이너 (`/math`)

중학교 3학년 수학 개념을 단원별로 정리하고, 학생이 **말로 설명한 내용**을 듣고 핵심 요소별로 채점해 부족한 부분을 되묻는 학습 앱입니다. 이해도 **90% 이상**이면 그 개념을 통과합니다.

## 학습 흐름

1. **개념 정리**: 핵심 개념, 꼭 기억할 식, 예제, 자주 하는 실수를 읽습니다.
2. **말로 설명하기**: 🎤 버튼을 누르고 친구에게 가르치듯 설명합니다. (브라우저 한국어 음성 인식, 직접 입력도 가능)
3. **채점과 피드백**: 개념마다 정해 둔 채점 기준표(핵심 요소 3~5개, 합계 100점)로 항목별 `충분/부족/빠짐/오류`를 판정하고, 잘한 점·오개념·피드백·되묻기 질문을 보여줍니다. 🔊 버튼으로 피드백을 들을 수 있습니다.
4. **보충 설명**: 되묻기 질문에 답하며 부족한 부분만 덧붙여 말합니다. 앞의 설명과 합쳐서 다시 채점합니다.
5. **통과**: 이해도 90% 이상이면 통과. 오개념이 남아 있으면 점수는 최대 85%로 제한되어 통과할 수 없습니다.

진도(개념별 최고 점수, 통과 여부)는 브라우저 localStorage에 저장됩니다.

## 단원 (25개 개념)

1. 제곱근과 실수 — 제곱근의 뜻과 성질, 대소 관계, 무리수와 실수, 근호를 포함한 식의 계산
2. 다항식의 곱셈과 인수분해 — 곱셈 공식, 인수분해의 뜻, 인수분해 공식
3. 이차방정식 — 뜻과 해, 인수분해 풀이, 제곱근·완전제곱식 풀이, 근의 공식
4. 이차함수와 그 그래프 — 뜻, y=ax², 평행이동, y=ax²+bx+c
5. 삼각비 — 뜻, 특수각, 활용
6. 원의 성질 — 원과 현, 접선, 원주각과 중심각, 원주각의 활용
7. 통계 — 대푯값, 분산과 표준편차, 산점도와 상관관계

## 채점 방식

- `OPENAI_API_KEY`가 있으면 AI 선생님이 채점 기준표의 항목별 판정과 피드백을 만들고, **점수는 서버가 항목 비중으로 직접 계산**합니다(AI가 점수를 임의로 주지 않도록).
- 키가 없거나 AI 호출이 실패하면 키워드 기반 간이 채점으로 동작합니다. (오개념 판별은 AI 모드에서만 가능)

## 주요 파일

- `lib/math3/curriculum.ts`: 단원·개념 정리·오개념·질문·채점 기준표 (내용 수정은 여기서)
- `lib/math3/scoring.ts`: 점수 계산, 키워드 간이 채점
- `app/api/math/evaluate/route.ts`: 설명 채점 API
- `app/math/page.tsx`: 단원 목록·진도 대시보드
- `app/math/ConceptStudy.tsx`: 개념 정리 → 말로 설명 → 피드백 화면
- `app/math/useSpeechRecognition.ts`: 한국어 음성 인식·읽어주기
